# Repo Operating Path Contributor Contract

This repository publishes a provider-neutral Agent Skill for defining, diagnosing, repairing, and proving repository operating paths.

## Priorities

1. Keep the skill portable across Claude and Codex.
2. Preserve the distinction between an eventual successful outcome and a clean operating path.
3. Repair the earliest owner-controlled divergence before adding reliability machinery.
4. Keep `SKILL.md` lean; put conditional detail in directly linked references.
5. Make claims only from the complete available execution record and authoritative state readback.

## Changes

1. Read the skill and its references before editing doctrine.
2. Do not add provider-specific paths, private environment assumptions, personal workflow history, secrets, or local absolute paths.
3. Do not add scripts unless repeated deterministic work proves that Markdown is insufficient.
4. Validate trigger clarity, reference links, portability, and the worked example before publishing.
5. Keep commits scoped and reviewable.
